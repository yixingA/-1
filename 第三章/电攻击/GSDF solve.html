一、通过小网络讲解功率转移因子法原理

    原理之前讲过：电气：通过转移因子算法求解潮流

1.算例1（2机3节点）

    如图是一个三节点的电力网络。支路参数见图。求解各线路的潮流     求解步骤如下：
  • 第一步：节点功率净输入向量Pij=[PG1,PG2,PG3-PD]，节点1对应PG1，节点2对应PG2，节点3对应PG3-PD
  • 第二步：取参考节点为1。
  • 第三步：初始化各节点功率为0，依次往各节点注入1单位功率，让功率从参考节点流出，求各条线路功率。见下表
  • 第四步：得到线路潮流 PL12=0PG1 -2/3PG2-1/3（PG3-PD）。PL13=0PG1-1/3/2PG2-1/3（PG3-PD）。PL23=0PG1+1/3PG2-1/3*(PG3-PD)

2 .算例2（2机3节点）

    如图所示的三节点系统中,节点1有两台发电机组，节点2分别有一台发电机组和一个负荷，节点3有一个负荷，三条支路的电抗都为0.25(标幺值)，试求DCPF（转移因子矩阵）中各个矩阵元素的值。

    求解步骤如下：

  • 第一步：节点功率净输入向量Pij=[P11+P12,P2-PD2,-PD3]
  • 第二步：取节点1为参考节点。
  • 第三步：初始化各节点功率为0，然后依次往各节点注入1单位功率，求解线路潮流。

    -得到线路功率

总结：转移因子法就是先确定一个参考节点，然后再其它节点加单位功率，然功率最终从参考节点流出。（计算流程有点像叠加定理。）

%%系统参数
%所有参数均用有名值表示
paragen=xlsread('excel2017','机组参数');
loadcurve=xlsread('excel2017','负荷曲线');
netpara=xlsread('excel2017','网络参数');
branch_num=size(netpara);%网络中的支路
branch_num=branch_num(1,1);%41条支路数
%机组数
gennum=size(paragen);
gennum=gennum(1,1);%机组数6个
%节点数
numnodes=size(loadcurve);
numnodes=numnodes(1,1)-1;%30个节点   

%时间范围
T=size(loadcurve);
T=T(1,2)-1;

%% 直流潮流下的导纳矩阵节点参数初始化
netpara(:,4)=1./netpara(:,4);%电抗求倒数成电纳
slack_bus=26;%按不同的平衡节点号更改 ，我选26是因为网络图中26只有一个相连接点，比较简单。
Y=zeros(numnodes,numnodes);
%% 直流潮流的导纳矩阵计算
for k=1:branch_num 
    i=netpara(k,2);%首节点
    j=netpara(k,3);%尾节点
    Y(i,j)=-netpara(k,4);%导纳矩阵中非对角元素
    Y(j,i)= Y(i,j);
end
for k=1:numnodes
       Y(k,k)=-sum(Y(k,:)); %导纳矩阵中的对角元素 
end

%再删除掉平衡节点所在的行与列
Y(slack_bus,:)=[];
Y(:,slack_bus)=[];
%% 输出功率转移分布因子(GSDF)
X=inv(Y);%X为直流潮流下节点导纳矩阵的逆矩阵
row=zeros(1,numnodes-1);%numnodes-1是因为节点导纳矩阵去掉了平衡节点 shape=1*29

%再次引入平衡节点的矩阵值，根据直流潮流定义ΔΘ=ΧΔP,平衡机角度始终为0，所以所有涉及平衡节点的X均为0
X=[X(1:slack_bus-1,:);row;X(slack_bus:numnodes-1,:)];%插入全0行
column=zeros(numnodes,1);
X=[X(:,1:slack_bus-1) column X(:,slack_bus:numnodes-1)];%插入全0列

G=zeros(branch_num,numnodes);%GSDF功率转移矩阵初始化
for k=1:branch_num
    m=netpara(k,2);%首端节点
    n=netpara(k,3);%末端节点
    xk=netpara(k,4);%支路k的阻抗值
for i=1:numnodes
    G(k,i)=(X(m,i)-X(n,i))*xk;%输出功率转移分布因子
end
end

3.python求解

import pandas as pd
import numpy as np

#读取文件
paragen=pd.read_excel('excel2017.xls',encoding='gbk',sheet_name='机组参数')#机组参数
loadcurve=pd.read_excel('excel2017.xls',encoding='gbk',sheet_name='负荷曲线')#负荷曲线
netpara=pd.read_excel('excel2017.xls',encoding='gbk',sheet_name='网络参数')#网络参数

branch_num=len(netpara)#支路数41
gennum=len(paragen)#机组数 6
numnodes=len(loadcurve)-1 #节点数30
T=np.array(loadcurve).shape[1]-1 #时间长度24

#直流潮流下的导纳矩阵节点参数初始化
netpara['支路电抗(p.u.)']=1.0/netpara['支路电抗(p.u.)'] #电抗求倒数成电纳
slack_bus=25 #按不同的平衡节点号更改,我取26 python计数从0开始计数。写的是25，其实26  26号节点只有一个相邻节点较为简单
Y=np.zeros(shape=(numnodes,numnodes)) #shape=(30,30)

#直流潮流的导纳矩阵计算
for k in range(branch_num):#遍历每一条支路
    i = netpara.iloc[k,1]-1 #首节点 #因为python从0开始编号，而文件是从1开始计数。所以减1
    j = netpara.iloc[k, 2]-1 # 尾节点 #因为python从0开始编号，而文件是从1开始计数。所以减1
    Y[i, j] = -netpara.iloc[k, 3]#导纳矩阵中非对角元素  互导纳
    Y[j, i] = Y[i, j]  #互导纳

for k in range(numnodes):#遍历每一个节点
    Y[k, k] = -sum(Y[k,:]) #导纳矩阵中的对角元素 (为某一行求和的负值） 自导纳为正

#再删除掉平衡节点所在的行与列
Y=np.delete(Y,25,axis=0)#删除第26行
Y=np.delete(Y,25,axis=1)#删除第26列
#print(Y.shape) #shape=(29,29)

#输出功率转移分布因子(GSDF)
X=np.linalg.inv(Y) #X为直流潮流下节点导纳矩阵的逆矩阵
row=np.zeros(shape=(1,numnodes-1))#numnodes-1是因为节点导纳矩阵去掉了平衡节点 shape=1*29

#再次引入平衡节点的矩阵值，根据直流潮流定义ΔΘ=ΧΔP,平衡机角度始终为0，所以所有涉及平衡节点的X均为0
X=np.insert(X, 25, values=row, axis=0) #在第25行 插入全0行 #X.shape=(30,29)
X=np.insert(X, 25, values=0, axis=1) #在第25列 插入全0列。 #X.shape=(30,30)

G=np.zeros(shape=(branch_num,numnodes)) #GSDF功率转移矩阵初始化 G.shape=(41,30)

for k in range(branch_num): #遍历每一条支路
    m = netpara.iloc[k, 1]-1 # 首端节点 #首节点 #因为python从0开始编号，而文件是从1开始计数。所以减1
    n = netpara.iloc[k, 2]-1 #尾节点 #因为python从0开始编号，而文件是从1开始计数。所以减1
    xk = netpara.iloc[k, 3] # 支路k的阻抗值
    for i in range(numnodes):#遍历每一个节点
        G[k, i] = (X[m, i] - X[n, i]) * xk #输出功率转移分布因子


#功率转移因子写入表格
G=pd.DataFrame(G,columns=['节点1','节点2','节点3','节点4','节点5','节点6','节点7','节点8','节点9','节点10',
                          '节点11','节点12','节点13','节点14','节点15','节点16','节点17','节点18','节点19',
                          '节点20','节点21','节点22','节点23','节点24','节点25','节点26','节点27','节点28','节点29','节点30'])

G=pd.concat([netpara[['编号','首端节点','末端节点']],G],axis=1)

G.to_csv('6机30节点的线路功率转移因子表.csv',index=False)

    求解结果见图，从图中看出25-26线路转移因子有很多1。因为26节点为参考节点，26节点相连节点只有25。意味着从其它节点注入1单位功率，最终流到25-26线路都必为1单位功率。从26号节点注入1单位功率，从26号节点流出，不经过25-26线路，所以该单元格为0。
